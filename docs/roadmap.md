# ロードマップ

現在の個人向けレシピ帳を基盤に、利用状況を見ながら次の順で拡張します。

## 登録を簡単にする

- Androidの共有先やiPhoneのショートカットからURLを渡せるようにする。
- 取得可能なサイトではタイトルなどを入力候補として表示する。取得できなくてもURL保存は続行できるようにする。
- 紙レシピをOCRで読み取り、確認後に材料候補を反映できるようにする。

## 探しやすくする

- 材料の同義語を増やす。
- 食材の親子カテゴリとOR検索を追加する。
- Cookpadに加え、利用条件と表示方法を確認できたサイトの料理画像に対応する。

## 利用範囲を広げる

- 家族を招待し、「誰が作ったか」も共有できるようにする。
- 複数端末での同期方法を検討する。
- 利用実績を踏まえ、ネイティブアプリが必要か判断する。

## 料理の計画につなげる

- 自作レシピの材料、分量、手順を編集できるようにする。
- 献立と買い物リストを検討する。

実装時は、端末内保存を基本とする現在のプライバシー方針、外部レシピの権利、オフライン時の挙動を各段階で見直します。
