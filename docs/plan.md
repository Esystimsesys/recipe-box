# ひとさじ プロダクト設計

## 目的

「ひとさじ」は、Webで見つけたレシピや紙のレシピを集め、料理写真やメモと一緒に残す個人向けPWAです。登録の手間を抑え、日常的に使える小さなレシピ帳を目指します。

## 基本方針

- ChromeとSafariを対象にしたレスポンシブなPWAとする。
- ログインを求めず、レシピと写真はブラウザのIndexedDBに保存する。
- 個人の記録を扱うサーバーは持たない。外部に出すのは、登録しようとしているリンクのURLだけに限る。
- 外部レシピの本文・手順・動画は取り込まず、元サイトへの導線を保つ。
- URLだけでも保存でき、名前・材料・写真・メモは任意入力とする。
- 紙面、料理写真、作った印をひとつのレシピにまとめる。
- データ移行と消失対策には、写真を含むJSONバックアップを使う。

アプリの公開と利用者の保存データは分離されています。現在のアプリに、個人の記録を公開する機能はありません。

## 主な操作

1. レシピサイトやSNSのURL、または紙面写真を登録する。
2. 名前、材料、メモ、出典、料理写真を追加する。
3. キーワード、材料、「作った」「お気に入り」から探す。
4. 外部レシピは元サイトで確認し、紙のレシピは保存した画像を拡大する。
5. 作ったアイコンを切り替え、料理写真やメモを残す。
6. 設定画面からバックアップを書き出し、必要な環境で取り込む。

材料検索は、指定した語が材料の一部に一致する部分一致検索で、複数指定時はAND条件です。ひらがな・カタカナや一部の基本的な表記ゆれを正規化します。登録されていない材料をアプリが推測して補完することはありません。

## データ設計

レシピは次の情報を持ちます。

- 種別（URLまたは紙）
- タイトル、元URL、出典
- 材料、個人メモ
- 料理写真、紙面写真
- 作った、お気に入り

旧バージョンの調理履歴は表示・登録しませんが、移行とバックアップ時に既存データを保持します。
- ID、作成日時、更新日時

更新日時を使い、別タブで変更されたレシピを古い編集画面から上書きしないようにします。バックアップはバージョン付きJSONとして構造、日付、ID、画像形式を検証してから取り込み、同じIDの既存レシピは上書きしません。

写真はブラウザ内で縮小・JPEG変換し、撮影メタデータと原寸データを保持しません。保存容量は端末とブラウザの制限を受けます。

## 技術構成

- React、TypeScript、Vite
- IndexedDB（idb）
- vite-plugin-pwa、Workbox
- Vitest
- Playwright（Chromium、WebKit）
- GitHub Pages
- Cloudflare Workers（リンクのタイトル取得のみ）

アプリ本体は静的ファイルだけで動作し、認証とクラウドデータベースを必要としません。レシピと写真を扱うサーバーは持たず、記録は端末内に留まります。唯一の例外が、リンクのタイトル取得用の小さなWorker（`worker/`）です。CORSヘッダーを返さないレシピサイトの`og:title`と`og:image`だけを読んで返し、ページ本文・手順・動画は読み取らず保存もしません。Workerが応答しなくても、タイトルが入らないだけでURLの保存は続きます。オリジンが変わると保存領域も変わるため、環境間の移行にはバックアップを使います。

## 段階的な拡張

| 段階 | 目的 | 主な機能 |
|---|---|---|
| 現行版 | 個人のレシピ帳として使う | URL・紙面・料理写真、部分一致検索、作った印、バックアップ、PWA |
| 登録支援 | 保存までの操作を短くする | 共有メニュー連携、タイトル候補、紙面OCRと材料候補 |
| 共有・検索拡張 | 複数人・複数端末で使う | 家族共有、同期、材料カテゴリ、OR検索 |
| 料理計画 | 保存したレシピを日々の計画に使う | 自作レシピ、献立、買い物リスト |

各機能の詳細は[ロードマップ](roadmap.md)を参照してください。

## 外部サービスとの関係

共有メニューからの登録はブラウザとOSによって対応状況が異なるため、URL貼り付けを共通の登録方法として維持します。Cookpadとクラシル公式レシピ（`/recipes/`）の公開画像は直接表示し、Instagramは公開埋め込みを使います。XはFxEmbedの公開APIから写真URLを取得します。TikTokなどの期限付きサムネイルは表示時に再取得します。料理写真があればそちらを優先し、外部画像本体は保存しません。

タイトルは、oEmbedを公開しているサイト（YouTube・TikTok）とXから直接取得し、それ以外は自前のWorkerを通して`og:title`を読みます。Workerに渡すのは登録しようとしているURLだけで、保存済みのレシピ・写真・メモは渡しません。参照元は「ひとさじ」の配信オリジンに限り、取得先は公開DNS名に限ります。
